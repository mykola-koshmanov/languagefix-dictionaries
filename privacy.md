# LanguageFix — Privacy Policy

_Last updated: 13 November 2026_

LanguageFix fixes words typed in the wrong keyboard layout on your Mac. It is built to work without collecting anything about you.

**What the app processes.** To recognise a word typed in the wrong layout, LanguageFix looks at the keys you type in the current text field. Only the current word is kept, in memory, and it is discarded when you switch apps, fields or move the cursor. Password fields and macOS Secure Input are never processed.

**What the app stores.** Only your settings and the word lists you create yourself (exceptions, personal dictionary), in the app's local preferences on your Mac. Typed text, clipboard contents and key presses are never written to disk or to logs.

**What the app sends.** Nothing about you. There is no analytics, telemetry, advertising or tracking. The network is used only when you ask to download a dictionary: the app requests a public file (for example `pl.txt`) from GitHub, and the request contains nothing but the file name. GitHub may log the request like any web server (see GitHub's privacy statement).

**Clipboard.** To replace selected text in some apps, LanguageFix briefly uses the clipboard and then restores what was there before. Clipboard contents are never stored or sent.

**Permissions.** Accessibility and Input Monitoring are required by macOS so the app can see typed keys and replace the mistyped word. They are used for nothing else.

**Children.** The app does not collect data from anyone, including children.

**Contact.** Questions: open an issue at https://github.com/mykola-koshmanov/languagefix-dictionaries/issues.
