# LanguageFix dictionaries

Word lists downloaded on demand by the LanguageFix macOS app (keyboard layout fixer) for languages
whose macOS spell checker is missing or does not work. One lower-case word per line, UTF-8.

The app downloads files from the `v1` release and accepts a file only if its SHA-256 matches the
value built into the app.

License: **CC BY-SA 4.0** — adapted from FrequencyWords (OpenSubtitles 2018). See `NOTICE.md`.
`build.py` rebuilds the lists from the pinned source.
